# Embedded-Systems-Lab

A collection of embedded systems experiments, implementations, and learning activities developed throughout my embedded systems journey.

This repository serves as a centralized record of my hands-on learning in:

* STM32 Register-Level Programming
* FreeRTOS on ESP32
* Embedded Data Structures

Each domain contains its own set of projects, experiments, and detailed documentation.

## Repository Structure

```text
Embedded-Systems-Lab/
├── STM32/
├── FreeRTOS/
└── Data_Structures/
```

## Purpose

The goal of this repository is to document practical learning, experimentation, and implementation of embedded systems concepts through code and projects.
